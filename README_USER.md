# AH Sniper — инструкция пользователя

AH Sniper показывает цены аукциона WoW, лоты со скидкой и BoE с нужными характеристиками. Приложение не управляет игровым клиентом; данные загружаются через Blizzard API.

## Установка

1. Получите пользовательский пакет у владельца сервиса.
2. Распакуйте его целиком в отдельную папку. Сохраните рядом с `AuctionMonitor.exe` файл `public_config.json`, справочники, БД и папку `icons/`, если они входят в пакет.
3. Запустите `AuctionMonitor.exe` и активируйте свой PRO-ключ. Лицензия приложения привязана к компьютеру.
4. В настройках укажите свои Blizzard API Client ID и Client Secret, полученные в [Developer Portal](https://develop.battle.net/), затем запустите сбор.

Не используйте `AuctionMonitorAdmin.exe`: это приватная версия владельца сервиса. Если пользовательский пакет содержит `.env` или `supabase_config.json`, сообщите об этом владельцу и получите корректный пакет.

## Поиск предметов

На вкладке снайпинга выберите или создайте пресет. Для обычных предметов включите `Snipe items`, добавьте ID и задайте минимальную скидку и среднюю цену. Предмет можно добавить из каталога кнопкой со звездой.

`BoE Snipe` включается отдельно. Его фильтры задают ilvl, вторичные статы, сокет и дополнительный эффект. Можно включить любой из двух режимов или оба. Пустой список ID не включает поиск всех обычных предметов.

Нажмите на предмет или цену, чтобы открыть карточку с предложениями по реалмам. Для BoE цена и характеристики относятся к конкретному варианту лота. Неизвестные характеристики не считаются отсутствующими. Avg — историческая средняя предмета/ilvl, а не отдельного сочетания статов.

## Пресеты

Изменения сохраняются автоматически. При проблеме облака интерфейс показывает локальный черновик и повторяет запись после восстановления. Не очищайте данные браузера или профиля приложения, пока черновик не сохранён.

В настройках доступны экспорт и импорт `presets.json`. Экспортируйте пресеты перед переносом на другую установку. Веб-пресеты относятся к аккаунту, локальные — к конкретной установке приложения.

## Если данных нет

- Проверьте Blizzard API и выбранный регион.
- Дождитесь завершения сбора: на новой установке истории цен может ещё не быть.
- Проверьте, что нужный режим поиска включён и фильтры допускают хотя бы один предмет.
- При проблеме лицензии проверьте `public_config.json` из пакета и доступность сервиса лицензий.

Адрес веб-версии, ссылку на обновления и канал поддержки предоставляет владелец сервиса. В исходниках и этой инструкции действующие адреса намеренно отсутствуют.
